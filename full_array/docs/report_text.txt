     Design, Simulation, and Layout of a 4 × 6 SRAM
            Array in 45 nm CMOS Technology
   EEE5322 • Fall 2026 • University of Florida

   Authors: __________________________________________________________

   Abstract—A 24-bit individually addressable SRAM was implemented with GPDK045 CMOS at 1.1
   V using native Cadence Virtuoso schematic, symbol, and layout views. The circuit integrates 371
   MOS transistors and operates at 20 MHz. All 24 cells pass write-one, write-zero, and
   mixed-pattern readback; repeated reads preserve the stored data. Nine process/temperature
   cases pass 852 schematic-level operations, and a device-extracted netlist passes a further 268
   operations. Nominal 50%-to-50% write-one/write-zero delays are 0.4152/0.2187 ns;
   read-one/read-zero delays are 0.3693/0.3859 ns. All 17 implemented cells and blocks have zero
   DRC violations and matching LVS. The complete layout measures 131.84 × 42.05 µm, or
   5543.872 µm².

   Index Terms—SRAM, 6T bitcell, decoder, precharge, differential sense amplifier, GPDK045,
   Spectre, DRC, LVS.

   I. INTRODUCTION
   The EEE5322 assignment requires four rows and six columns with individually addressed bits
   [1]. A pair of cross-coupled CMOS inverters stores each bit, and two access devices connect it to
   complementary bitlines. The project includes the transistor design, reusable logic cells, memory
   peripherals, full-array simulation, physical layout, and independent layout verification. This
   report follows the section structure of the supplied reference report [5]; its measurements and
   verification results come from the new 4 × 6 implementation.

   II. DESIGN OVERVIEW
   R1:R0 selects one of four rows. C2:C1:C0 selects columns 0–5; 110 and 111 select no column.
   The logical address used in the validation tables is a = 6r + c, with r = 2R1 + R0 and c = 4C2 +
   2C1 + C0. CLK2 controls precharge; CLK1 enables the requested read or write after precharge
   ends. DIN is the write input and DOUT is the latched read output. All blocks use explicit VDD
   and GND connections.

    Interface                                         Meaning

    R1, R0 / C2, C1, C0                               2 row bits / 3 column bits

    CLK1 / CLK2                                       Access clock / active-high precharge phase

    WR / RD                                           Exclusive write / read request

    DIN / DOUT                                        Single-bit input / held single-bit output

    VDD / GND                                         1.1 V supply / explicit ground

   III. IMPLEMENTATION

   A. SRAM Bitcell and Reusable Logic
   The 6T cell uses 120 nm PMOS pull-ups, 240 nm NMOS access devices, and 360 nm NMOS
   pull-downs; all channel lengths are 45 nm. The width ratios PD/access = 1.5 and access/PU = 2
   strengthen the pull-down against read disturbance while retaining write ability. A
   minimum-width all-120 nm baseline is retained in the separate single-cell study. That study
   measures a nominal read static-noise margin of 223.58 mV for the final sized cell [6]. Full-array
   nondestructive readback is verified separately here.

   The compact layout preserves the supplied arrangement: cross-coupled inverter devices in the
   center and staggered access devices on either side. Its boundary is 2.12 × 1.68 µm (3.5616 µm²),
   including explicit body taps. Poly runs vertically; metal interconnect closes the feedback loop.
   The cell is repeated on a 2.30 × 2.02 µm placement pitch in the array.

   B. Row Decoder
   The enabled 2-to-4 row decoder contains two address inverters and four AND3 minterms. WLr =
   ROWEN AND the row-address minterm for r. Thus exactly one wordline is high during a valid
   access, and all wordlines are low during idle, precharge, invalid columns, or conflicting
   commands. Eight unit vectors cover both enable values and every row address.

   C. Column Decoder and Selection
   The 3-to-6 column decoder contains three input inverters and six AND3 minterms. CS0–CS5
   decode 000–101. No minterm exists for 110 or 111, so both unused addresses produce six low
   outputs. Each CS controls two transmission gates joining one physical bitline pair to GBL/GBLB.
   Unit simulation covers all eight codes; array tests exercise both invalid codes on every row for
   reads and writes.

   D. Precharge Circuit
   Each column has two 1080 nm PMOS devices charging BL and BLB to VDD and a third PMOS
   equalizing the pair. PCB = NOT CLK2 is the active-low gate signal. All six pairs precharge
   together before access. Both bitlines approach 1.1 V, as required; they are not biased to half
   supply. The measured 10%–90% recharge time for a discharged bitline is 0.1181 ns under the
   stated schematic testbench load.

   E. Read/Write Circuitry and Sense Amplifier
   The control logic defines VALID = NOT(C2 AND C1), WEN = CLK1 AND WR AND NOT(RD) AND
   VALID AND NOT(CLK2), and REN = CLK1 AND RD AND NOT(WR) AND VALID AND
   NOT(CLK2). ROWEN = WEN OR REN. Therefore precharge and access are interlocked, invalid
   columns disable access, and simultaneous RD/WR commands disable both paths. Normal
   stimulus keeps RD and WR exclusive; separate fault tests deliberately assert conflicts to verify
   the hardware protection.

   The write driver inverts DIN and uses complementary-enabled transmission gates to drive
   GBL/GBLB only when WEN is high. It presents high impedance when disabled. The sense
   amplifier is a five-transistor NMOS differential OTA with a PMOS mirror load, followed by a
   CMOS output inverter (seven transistors total). The input devices are 240 nm, mirror devices
   1440 nm, and tail/output-inverter devices 360 nm. The polarity is DOUT = 1 when BIT exceeds
   BIT_bar. Six standalone tests include both polarities of a 100 mV difference at common-mode
   voltages 1.05 V and 0.75 V, as well as rail-to-rail differential inputs.

   The contribution fields are intentionally blank for the submission authors to complete. The main
   circuit challenge was resolving a small negative differential near VDD at the sense input. The
   initially explored sizing did not reliably meet the standalone low-output rail criterion for this
   case. A sizing sweep and repeat simulation led to the final 240 nm input / 1440 nm mirror / 360
   nm tail combination. The final six input cases and all array corner cases pass.

   The physical-design challenges were preserving explicit ground connectivity, meeting small
   metal landing-area rules, and routing hierarchical ports without accidental shorts. Directional
   via landings and separated routing channels resolved these issues. The full default DRC deck is
   used, and LVS compares extracted devices against a CDL export of the actual saved native
   schematics. No DRC or LVS waiver is used.

   V. SIMULATION RESULTS

   A. Testbench and Timing Setup
   Spectre 21.1.0.664 runs the supplied GPDK045 BSIM models at VDD = 1.1 V. The main case is
   TT, 27 °C. A 50 ns period gives 20 MHz, above the 10 MHz requirement. Inputs settle at 0.2–0.3
   ns within each cycle; CLK2 rises at 2.0–2.1 ns and falls at 12.0–12.1 ns. CLK1 rises at 20.0–20.1
   ns and falls at 40.0–40.1 ns. Thus nominal precharge and access do not overlap. Address and
   data are held throughout the access.

   The schematic fixture adds 20 fF to each of 12 physical bitlines, 5 fF to each global bitline, and
   10 fF at DOUT. Initial conditions set storage nodes only at simulation start; they do not force a
   stored bit during operation. A complete write phase precedes every read phase. Coverage
   simulations use a maximum 500 ps timestep and 500 ps saved strobes. Every operation checks
   all 24 Q/Qbar pairs at 37 ns in its cycle with 0.1VDD/0.9VDD rail limits. DOUT is checked on
   reads, wordlines and selects are checked for proper enabling, and later read scans verify
   retained data.

   B. All-Address Functional Validation
   At nominal conditions, the sequence writes all 24 ones and reads every address twice, then
   writes all 24 zeros and reads every address twice, then writes the explicit mixed sequence
   100110101001011001110010 and reads every address twice. The mixed rows are 100110 /
   101001 / 011001 / 110010. Two scans after each write phase demonstrate repeated
   nondestructive readback. Every write also checks that all other cells retain their expected states,
   including unselected cells on an active row.

   The Pegasus-extracted flat netlist contains 371 MOS transistors. It was converted directly into a
   Spectre subcircuit, preserving extracted device dimensions and source/drain geometry
   parameters. The nominal replay executes 268 operations, including 72 writes, 168 reads, and 28
   protection operations. It adds a final complete read scan after all faults; all outputs match the
   expected state. No initial storage-node forcing is used in this extracted replay; the initial
   complete write establishes the contents.

   This is a device-extracted topology simulation. It includes intrinsic model/device capacitances
   and a 10 fF output load, with no added schematic bitline load. It does not contain extracted
   interconnect resistance/capacitance. Therefore the four reported timing values are
   schematic-fixture measurements, and are not claimed as full RC post-layout timing. Nineteen
   final Spectre jobs (nine array, eight unit, one fine timing, and one extracted array) finish with
   zero simulator errors and zero warnings. The unit jobs cover 110 input vectors.

   VII. CONCLUSION
   The 4 × 6 SRAM integrates all required memory and peripheral blocks, writes and reads every
   valid address at 20 MHz, and preserves data over repeated reads and protection tests. Both data
   polarities have explicit 50%-to-50% timing markers. All 17 layouts have zero DRC violations and
   matching LVS, and the extracted transistor circuit reproduces the expected output sequence.
   Native Cadence views, simulation decks and waveforms, verification logs, scripts, and editable
   report are supplied for review and reproduction. Further optimization could reduce peripheral
   routing area and characterize full interconnect-RC timing.
